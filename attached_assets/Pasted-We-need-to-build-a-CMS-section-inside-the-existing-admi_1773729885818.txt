We need to build a CMS section inside the existing admin panel. This is our editorial control room — a clean interface for viewing and editing all the content that powers the public site and the logged-in product. Everything reads from and writes back to the existing database. No new data sources. No hardcoded content. No new tables unless absolutely necessary and approved first.
How our content is created — read this first
Everything starts with a transcript pulled from Taddy. That transcript is sent to OpenAI, which generates all the structured content you see on the site — recaps, takeaways, quotes, people mentioned, companies mentioned, books mentioned, products mentioned, topics, and key ideas. That content is stored in the database. The CMS is a window into what OpenAI produced, with the ability to review and edit anything before it appears on the public site.
The transcript is the source of truth for every episode. It is always read-only — never editable. Everything generated from it can be edited. The transcript itself never changes.
What to build
A CMS section with five top-level sections in the nav: Podcasts, Episodes, People, Companies, and Products.
Each section is a searchable, sortable list of everything in the database for that content type. Clicking into any item opens a detail view where you can see and edit all the fields for that item.
The hierarchy
Episodes live inside Podcasts — when viewing a podcast you can navigate directly to its episodes. People, Companies, and Products are their own top-level sections.
