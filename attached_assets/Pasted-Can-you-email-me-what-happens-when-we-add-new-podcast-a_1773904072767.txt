"Is chunking still needed after removing all those fields?"
Yes, chunking is still needed. The issue isn't what you're extracting — it's the size of the transcript itself. GPT-4o has a context window limit, and long podcast transcripts (a 3-hour episode can be 100,000+ characters) simply won't fit in a single API call. The 28,000 character threshold exists because the transcript plus the prompt plus the expected output need to fit within the token limit. With a simpler prompt you might be able to bump that threshold up a bit (maybe to 35,000-40,000), but you can't eliminate chunking entirely for long episodes.
